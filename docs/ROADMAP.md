# Subzero Tracker — Roadmap

## Docs: write the user guide

Write a short user guide covering installation, first run, and the core
add / list / finish commands, so the study group can try the tool without
reading the source.

## CI: wire up the test workflow

Stand up a GitHub Actions workflow that runs the test suite on every pull
request, so early contributions stay green.

## Release: tag v0.1.0

Cut the first release: finalize the changelog, tag `v0.1.0`, and publish it
so there is a stable point to demo.
