# Subzero Tracker — Overview

Subzero Tracker is a tiny command-line tool for tracking side-project tasks.
It is intentionally small: a single CLI, a plain-text task list, and just
enough structure to keep momentum on weekend projects.

## Goals

- Zero-install feel: a single Python entry point, no heavy dependencies.
- Fast task capture: add, list, and finish tasks without leaving the terminal.
- Readable storage: tasks live in a simple file you can read, diff, and back up.

## Current state

The project is at the very start of its life: this branch contains the initial
scaffold of documentation and a stub CLI entry point. The next steps are
tracked on the roadmap.
